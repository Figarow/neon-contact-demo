# NEON CONTACT — Connect Beyond · Werbeseite & Demo

Diese Repository enthält die **offizielle Werbe-/Landingpage** für
**NEON CONTACT: CONNECT BEYOND**, ein futuristisches 3D-Sci-Fi-Laserpuzzle
(Three.js / WebGL2), inklusive Gameplay-Demo-Video und Downloads der
spielbaren Demo für Windows und Linux.

## 🌐 Live ansehen

Öffne `index.html` im Browser oder aktiviere GitHub Pages für dieses Repo
(Settings → Pages → Branch `main` → Root).

## 🎮 Über das Spiel

**NEON CONTACT: CONNECT BEYOND** lässt dich Laserstrahlen per Spiegel,
Teiler und Verstärker durch eine isometrische 3D-Szene lenken, um Kontakt
zu einer fernen Welt herzustellen. Echtzeit-Raycasting-Physik, Cyberpunk-
Neonoptik (Cyan/Magenta/Grün) und handgebaute Rätsel bilden den Kern des
Gameplays.

- Engine: Three.js (WebGL2)
- Plattformen: Browser, Windows, Linux
- Status: Pre-Alpha — spielbarer Vertical Slice / Demo 1
